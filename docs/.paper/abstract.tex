We present MAgHARCM (Multi-Agent Harness for Archaeology-guided Repository-level Code Migration), an end-to-end repository-level translation engine implemented in Go on top of CloudWeGo Eino, designed to run entirely against locally-hosted small language models (SLMs) via Ollama. Extending the ReCodeAgent multi-agent paradigm, MAgHARCM introduces a principled 6-stage pipeline (Intake $\rightarrow$ Analyze $\rightarrow$ Plan $\rightarrow$ Translate $\rightarrow$ Validate $\rightarrow$ Repair) grounded in 26 evidence-backed methodology primitives. Key architectural advancements include: (1)~\emph{Chunked Translation} (NEW-PRIM-23) with topological batch dispatch and compact prior-emitted module summaries to overcome the single-shot context saturation ceiling; (2)~\emph{Symbol-Aware Navigation} (NEW-PRIM-26) for precise $\le 4$\,KB context retrieval; (3)~\emph{Reverse-Topological Scheduling with Back-Edge Removal} (NEW-PRIM-1/2) for cycle-free dependency ordering; (4)~\emph{Source-to-Target Manifest Rewriting} (NEW-PRIM-31) for automated build configuration synthesis; (5)~\emph{Adversarial Weakening Guards} (NEW-PRIM-13) to prevent test relaxation during repair; (6)~\emph{Plateau-Bounded Test Remediation} (NEW-PRIM-27) derived from CodaMOSA; and (7)~\emph{Conversable Checkpointing} (NEW-PRIM-28) for idempotent run persistence. We evaluate MAgHARCM on four representative multi-language benchmarks across C, Go, and Java (GildedRose, Oxidizer \texttt{stats}, Oxidizer \texttt{gohistogram}, and AlphaTrans \texttt{commons-validator}) translated to Rust. Our results show that GildedRose achieves 100\% compilation and 100\% test pass rate (4/4 tests), while larger multi-file repositories expose distinct throughput and borrow-checker boundaries that validate the necessity of chunked, symbol-guided decomposition.
