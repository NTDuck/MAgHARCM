\begin{abstract}
Repository-scale software translation across programming languages is a necessary task in software engineering. While Large Language Models (LLMs) synthesize standalone functions accurately, migrating multi-file repositories introduces cross-file type dependencies, cyclic references, and context saturation. Existing multi-agent frameworks address these issues by using closed-source commercial cloud models with large context windows. This approach creates high monetary cost, high execution latency, and data privacy risks.

We present \textbf{MAgHARCM} (\textbf{M}ulti-\textbf{Ag}ent \textbf{H}arness for \textbf{A}rchaeology-guided \textbf{R}epository-scale \textbf{C}ode \textbf{M}igration). MAgHARCM is an open-source translation harness designed to execute on local Small Language Models (SLMs) through Ollama. MAgHARCM coordinates four specialized agents: (1)~an \textbf{Analyzer Agent} that selects migration scope, (2)~a \textbf{Planning Agent} that builds a cycle-free reverse-topological dependency DAG with canonical manifest rewriting, (3)~a \textbf{Translator Agent} that uses chunked translation bounded by a $\le 4$\,KB Symbol Navigator and Prior-Modules Memory, and (4)~a \textbf{Validator Agent} that executes compiler build checks, test execution, an adversarial test-weakening guard, and coverage plateau detection.

We evaluate MAgHARCM on four benchmark repositories across C, Go, and Java targeting Rust across $K=3$ stochastic runs. Using a local 30B reasoning model paired with a 4B coding model, MAgHARCM achieves a 100\% compilation and test pass rate on algorithmic code (GildedRose), 66.7\% compilation on streaming libraries (Gohistogram), and 42.9\% test pass rates on statistical suites (Stats). We formalize an empirical failure taxonomy showing borrow-checker lifetime errors (38\%) and cyclic references (26\%) as key bottlenecks for local automated migration.
\end{abstract}
