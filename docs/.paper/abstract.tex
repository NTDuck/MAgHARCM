\begin{abstract}
Automated repository-scale code migration across programming languages is a critical challenge in software engineering. While Large Language Models (LLMs) excel at function-level synthesis, migrating multi-file repositories introduces inter-module type dependencies, cyclic references, and context window saturation. Existing multi-agent frameworks address these challenges by relying on massive, closed-source commercial cloud models with multi-million-token context budgets, creating substantial cost, latency, and data privacy barriers.

In this paper, we present \textbf{MAgHARCM} (\textbf{M}ulti-\textbf{Ag}ent \textbf{H}arness for \textbf{A}rchaeology-guided \textbf{R}epository-scale \textbf{C}ode \textbf{M}igration), an open-source, modular translation engine designed to execute entirely on local, quantized Small Language Models (SLMs) via Ollama. MAgHARCM coordinates four specialized agents over an explicit pipeline: (1)~an \textbf{Analyzer Agent} implementing M\"uller migration strategy selection, (2)~a \textbf{Planning Agent} constructing a cycle-free reverse-topological dependency DAG with canonical manifest rewriting, (3)~a \textbf{Translator Agent} employing chunked translation bounded by a $\le 4$\,KB Symbol-Aware Navigator and Prior-Modules Memory, and (4)~a \textbf{Validator Agent} providing multi-stage build/test feedback, an adversarial test-weakening guard, and CodaMOSA-derived coverage plateau detection.

We evaluate MAgHARCM on four real-world benchmark repositories across C, Go, and Java targeting Rust across $K=3$ stochastic runs without artificial timeouts. Using a 30B reasoning model paired with a 4B coding model locally, MAgHARCM achieves a 100\% compilation and test pass rate on algorithmic katas (GildedRose), 66.7\% compilation on streaming libraries (Gohistogram), and 42.9\% test pass rates on multi-file statistical suites (Stats). We formalize an empirical failure taxonomy showing borrow-checker lifetime errors (38\%) and cyclic references (26\%) as the primary bottlenecks for local automated migration.
\end{abstract}
