Automated repository-scale code migration across programming languages is essential for system modernization, performance optimization, and memory-safety refactoring. However, existing approaches based on monolithic Large Language Models (LLMs) suffer from severe compilation failures and context saturation when applied to multi-file projects with complex dependency graphs, cyclic type hierarchies, and distinct memory management semantics. Furthermore, state-of-the-art multi-agent frameworks predominantly rely on proprietary commercial cloud APIs with multi-million-token contexts, rendering them impractical for privacy-sensitive enterprise deployments with local resource constraints.

In this paper, we introduce \textbf{MAgHARCM} (\textbf{M}ulti-\textbf{Ag}ent \textbf{H}arness for \textbf{A}rchaeology-guided \textbf{R}epository-scale \textbf{C}ode \textbf{M}igration), a modular, agentic translation engine designed to execute entirely on locally-hosted Small Language Models (SLMs). MAgHARCM decomposes repository translation into a coordinated four-agent workflow---\emph{Analyzer}, \emph{Planning}, \emph{Translator}, and \emph{Validator}---governed by an explicit reverse-topological dependency directed acyclic graph (DAG). To enable local models ($\le 8\text{B}$ parameters) to operate effectively without context saturation, MAgHARCM introduces: (1)~\emph{Reverse-Topological Slicing} with back-edge cycle elimination to translate dependency callees before dependent callers; (2)~\emph{Bounded Context Assembly} featuring a Symbol-Aware Navigator and compact Prior-Modules Memory ($\le 4$\,KB budget); (3)~\emph{M\"uller Migration Strategy Selection} for tailored project-scale scoping; and (4)~\emph{Dual-Stage Validation} integrating pre-compilation AST syntax verification, target build compilation, a CodaMOSA-derived coverage plateau stall detector, and an adversarial test-weakening guard to guarantee behavioral preservation.

We evaluate MAgHARCM across four benchmark repositories spanning C, Go, and Java sources targeting Rust under a local dual-model topology (Liquid MoE 8B for reasoning and Qwen3-4B for coding). Across $K=3$ multi-run stability trials, MAgHARCM achieves clean compilation and 100\% test pass rate on algorithmically dense kata benchmarks, and provides actionable, structured compilation feedback across large-scale multi-file codebases. Finally, we formalize a comprehensive taxonomy of repository-scale translation failure modes, identifying borrow-checker lifetime aliasing and cyclic package visibility as the primary frontiers for local SLM code synthesis.
