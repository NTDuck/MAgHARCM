Automated repository-scale code migration across programming languages is essential for system modernization, performance optimization, and memory-safety refactoring. However, existing approaches based on monolithic Large Language Models (LLMs) suffer from severe compilation failures and context saturation when applied to multi-file projects with complex dependency graphs, cyclic type hierarchies, and distinct memory management semantics. Furthermore, state-of-the-art multi-agent frameworks predominantly rely on proprietary commercial cloud APIs with multi-million-token contexts, rendering them impractical for privacy-sensitive enterprise deployments with local resource constraints.

In this paper, we introduce \textbf{MAgHARCM} (\textbf{M}ulti-\textbf{Ag}ent \textbf{H}arness for \textbf{A}rchaeology-guided \textbf{R}epository-scale \textbf{C}ode \textbf{M}igration), a modular, agentic translation engine designed to execute entirely on locally-hosted Small Language Models (SLMs) and quantized reasoning engines. MAgHARCM decomposes repository translation into a coordinated four-agent workflow---\emph{Analyzer}, \emph{Planning}, \emph{Translator}, and \emph{Validator}---governed by an explicit reverse-topological dependency directed acyclic graph (DAG). To enable local models to operate effectively without context saturation, MAgHARCM introduces: (1)~\emph{Reverse-Topological Slicing} with back-edge cycle elimination to translate dependency callees prior to callers; (2)~\emph{Bounded Context Assembly} featuring a $\le 4$\,KB Symbol-Aware Navigator and compact Prior-Modules Memory; (3)~an \emph{Adversarial Weakening Guard} that halts execution if test assertions are removed or degraded during repair; and (4)~a \emph{CodaMOSA-derived Coverage Plateau Detector} that dynamically detects convergence limits.

We evaluate MAgHARCM across four real-world benchmark repositories spanning C, Go, and Java sources targeting Rust under a local dual-model topology: a 30B parameter thinking model (\texttt{qwen3:30b-thinking}) for architectural planning and dependency analysis paired with an instruction-tuned 4B coding model (\texttt{Qwen3-4B-Instruct}) for exact Rust synthesis. Across stochastic multi-run stability trials ($K=3$), we track per-sample compilation rates and test pass rates across all repair iterations without artificial wall-clock timeouts. MAgHARCM achieves a 100\% compilation rate and 100\% test pass rate on algorithmically dense kata benchmarks, a 66.7\% compilation rate (62.5\% test pass rate) on numeric libraries, and systematically resolves multi-module structures on enterprise codebases. Finally, we formalize a comprehensive empirical failure taxonomy, identifying borrow-checker lifetime aliasing (38\%) and cyclic package visibility (26\%) as the dominant frontiers for local automated code migration.
