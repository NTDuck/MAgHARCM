\section{Related Work}
\label{sec:related}

\subsection{Rule-Based Transpilation \& Migration}
\label{sec:related_transpilers}

Traditional code translation systems use deterministic abstract syntax tree (AST) transformations. \textsc{C2Rust}~\cite{c2rust} translates C code into Rust by preserving C memory layouts and emitting \texttt{unsafe} blocks with raw pointers. While semantics are preserved, the generated Rust code requires extensive human refactoring to achieve idiomatic safety~\cite{siddiq2024oxidizer}. Similarly, tools like \textsc{CXGO} and \textsc{Java2Rust} rely on hand-engineered mapping rules that do not easily generalize across divergent type systems and idiomatic concurrency models.

\subsection{Neural Code Translation}
\label{sec:related_neural}

Neural approaches formulate source code translation as sequence-to-sequence generation. \textsc{TransCoder}~\cite{roziere2020transcoder} introduced unsupervised machine translation for programming languages using cross-lingual masked language modeling. Follow-up works like \textsc{AlphaTrans}~\cite{yang2024alphatrans} added modular call-graph analysis and iterative feedback. However, these systems operate at single-function or single-file scopes, failing to resolve repository-level inter-module references.

\subsection{Multi-Agent Software Engineering Systems}
\label{sec:related_mas}

Multi-agent software engineering frameworks coordinate specialized agents over discrete development roles. \textsc{MetaGPT}~\cite{hong2023metagpt} incorporates standard operating procedures to structure multi-agent communication. \textsc{ChatDev}~\cite{qian2023chatdev} uses communicative de-hallucination loops to generate software projects. \textsc{ReCodeAgent}~\cite{ibrahimzada2026recodeagent} applied multi-agent decomposition to repository translation, reporting substantial compilation gains over monolithic prompting. However, these frameworks depend on large cloud LLMs with multi-million-token context windows. MAgHARCM demonstrates that repository translation can execute entirely on local, quantized SLMs through reverse-topological scheduling and bounded context navigation.
