\section{Conclusion}
\label{sec:conclusion}

In this paper, we introduced \textbf{MAgHARCM}, a modular multi-agent harness for repository-scale code translation engineered to execute entirely on locally-hosted Small Language Models (SLMs). By decomposing repository translation across four cooperating agents---Analyzer, Planning, Translator, and Validator---and grounding execution in reverse-topological dependency graphs, bounded context assembly ($\le 4$\,KB Symbol Navigator and Prior Memory), adversarial weakening guards, and coverage plateau stall detection, MAgHARCM bridges the gap between single-function neural code translation and multi-file enterprise repository migration.

Our empirical evaluation across C, Go, and Java benchmarks targeting Rust demonstrates that local model topologies (Liquid MoE 8B reasoning paired with Qwen3-4B coding) can achieve clean compilation and 100\% test pass rates on algorithmic katas without relying on cloud APIs or leaking proprietary intellectual property. Furthermore, our qualitative analysis provides a structured failure taxonomy, establishing that ownership aliasing under strict borrow checkers and cyclic package dependencies constitute the primary technical frontiers for automated code synthesis.

In future work, we plan to incorporate speculative AST-level type deduction, parallel multi-agent repair branches, and dynamic lifetime annotation synthesis to further extend the capabilities of local SLMs on large-scale enterprise software migration.
